手动备份（备份 Gist）

备份目标
用于「手动备份」的独立 Token，与上方日常同步 Token 分开填写（同一 GitHub 账号即可）。
建议使用一个独立的 Secret Gist 存放历史备份，不参与日常自动同步，避免被自动合并覆盖。
备份目标：WebDAV 网盘（坚果云等），与「云端同步」共用同一套服务器地址、账号和密码，无需单独填写。
备份文件 crm-backups.json 与主数据 crm-data.json 同目录；快照按下方「保留备份数量」自动清理；不受 Gist 1MB 限制。
